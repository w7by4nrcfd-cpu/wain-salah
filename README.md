# وين الصلاة

تطبيق ويب عربي لمواقيت الصلاة وأقرب المساجد.

- مواقيت الصلاة بتقويم أم القرى، مع عدّاد للصلاة القادمة وأوقات الإقامة.
- أقرب المساجد حسب موقعك من بيانات OpenStreetMap، مع المسافة ومدة المشي والاتجاه وزر للاتجاهات.
- بوصلة قبلة حيّة.
- يُثبّت على الشاشة الرئيسية ويعمل بدون إنترنت بعد أول فتح.

بدون خادم أو مكتبات: HTML وCSS وJavaScript فقط.
