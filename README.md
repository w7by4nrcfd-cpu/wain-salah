# مُصلّى

تطبيق ويب عربي لمواقيت الصلاة.

- مواقيت الصلاة بتقويم أم القرى حسب موقعك، مع عدّاد للصلاة القادمة ووقت الإقامة التقريبي.
- أوقات الضحى ومنتصف الليل والثلث الأخير.
- وضع رمضان (الإفطار والإمساك) ووضع الجمعة يظهران تلقائياً.
- البحث عن أقرب مسجد أو مصلى نساء في خرائط Google.
- أذكار بعد الصلاة من حصن المسلم مع عدّاد.
- بوصلة قبلة حيّة.
- يُثبّت على الشاشة الرئيسية ويعمل بدون إنترنت بعد أول فتح.

بدون خادم أو مكتبات: HTML وCSS وJavaScript فقط.
